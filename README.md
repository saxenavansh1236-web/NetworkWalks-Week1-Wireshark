# NetworkWalks – Week 1: Wireshark Network Traffic Analysis

## 📌 Project Overview

This repository contains my Week 1 cybersecurity project work completed as part of the NetworkWalks program.

The project focuses on understanding network traffic analysis using **Wireshark** and exploring how network communication can be captured, inspected, and analyzed.

## 🎯 Objectives

- Understand the basics of network traffic analysis.
- Capture and inspect network packets using Wireshark.
- Identify different network protocols.
- Analyze TCP communication and network connections.
- Understand how packet analysis helps in cybersecurity investigations.

## 🛠️ Tools & Technologies

- Wireshark
- Oracle VirtualBox
- Kali Linux
- Windows (Lab Environment)
